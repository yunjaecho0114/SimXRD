# XRD Simulation and Physical-Variable Labeling

## Research collaboration codebase

This directory provides examples of simulated powder X-ray diffraction (XRD) generation and **actual lattice-strain labeling** using the SimXRD simulation engine. The goal is to support AI models that infer physical or processing variables from diffraction patterns. The initial regression target is lattice strain.

This is an extension of the original SimXRD software. The examples are small, inspectable demonstrations; the full research dataset is not included.

### Code navigation

The main research code is organized as follows:

- [XRD simulation examples](examples/) — Ideal XRD, perturbed XRD, and strain labeling.
- [Production DB pipeline](../db_expansion/) — Structure selection, simulation utilities, and dataset generation.
- [Original SimXRD engine](../src/Pysimxrd/) — Underlying XRD simulation implementation.
- [Git configuration](../.gitignore) — Files excluded from version control.

### Research workflow

```text
Crystal structure (ASE Atoms)
      |---> Undeformed reference ---> Ideal stick XRD (3500 points)
      |
      '---> Controlled lattice deformation
                   |---> Lattice matrices A0, A1 ---> Actual strain labels
                   '---> Deformed structure ---> SimXRD ---> Perturbed XRD (3500 points)

Paired XRD (ideal, perturbed) ---> ML model ---> Predicted strain RMS
```

A perturbed-only single-channel model is also a relevant baseline.

## 2. Example structure and XRD grid

The default example uses AgTlTe2 (`sim/demo_mp.db`, ASE entry 8). To use another structure, supply `--db` and `--entry-id`. Distribution rights for structure databases must be checked before sharing them externally.

All three examples use:

- 2-theta values from 10.00° to 79.98° in increments of 0.02° (`np.arange(10.0, 80.0, 0.02)`).
- A 3,500-point intensity vector, normalized to a maximum intensity of 100.
- An **ideal reference** consisting of calculated Bragg stick peaks binned onto this grid.
- A **perturbed profile** generated by the SimXRD peak-shape engine.

These channels have different representations (binned sticks versus a simulated continuous profile).

## 3. Example 01 — Generate ideal XRD

**File:** `collaboration/examples/01_ideal_xrd.py`

```bash
python collaboration/examples/01_ideal_xrd.py --entry-id 8
```

The script loads an undeformed crystal structure, calculates ideal Bragg peak positions and intensities with `get_diff()`, maps them onto the shared grid, and writes:

```text
collaboration/outputs/ideal_entry_8.npy
collaboration/outputs/ideal_entry_8.dat
collaboration/outputs/ideal_entry_8.png
```

The `.npy` array has shape `(3500,)`. The `.dat` contains two-theta and intensity columns. The plot visualizes both raw stick peaks and the gridded reference.

## 4. Example 02 — Generate perturbed XRD

**File:** `collaboration/examples/02_simulate_xrd.py`

```bash
python collaboration/examples/02_simulate_xrd.py \
  --entry-id 8 \
  --grain-size-nm 10 \
  --stretch-bound 0.01 \
  --shear-bound 0 \
  --seed 0
```

The script accepts grain size, thermal displacement, orientation-related peak-intensity randomness, lattice stretch/shear bounds, background ratio, noise ratio, and random seed. It outputs a paired XRD `.npz`, simulation settings `.json`, and comparison `.png` under `collaboration/outputs/`.

**Simulation settings are not measured labels.** For example, `--stretch-bound 0.01` controls the range used for random deformation; it does **not** mean the realized strain RMS is 0.01. This example intentionally does not report an actual strain label.

The pymatgen-based simulation path (`sim_model=None`) does not apply the `zero_shift` argument, so that control is not exposed by this example. The orientation parameter is a simplified random per-peak intensity factor, not a full crystallographic texture model. The optional noise is positive uniform additive noise, not Gaussian noise.

## 5. Example 03 — Generate paired XRD with actual strain labels

**File:** `collaboration/examples/03_strain_labeling.py`

```bash
python collaboration/examples/03_strain_labeling.py \
  --entry-id 8 \
  --grain-size-nm 10 \
  --stretch-bound 0.01 \
  --shear-bound 0 \
  --seed 0
```

This example:

1. Calculates the undeformed ideal XRD and conventional-cell lattice matrix `A0`.
2. Applies **one** random lattice deformation using `prim2conv()` and obtains `A1` and the deformed structure.
3. Calculates actual relative changes in the conventional-cell axis lengths.
4. Simulates perturbed XRD from that **same deformed structure**, with `deformation=False` to avoid a second deformation.
5. Saves XRD arrays, lattice matrices, calculated labels, JSON metadata, and a comparison plot.

For conventional-cell axis lengths a, b, and c:

```text
strain_a = (a_after - a_before) / a_before
strain_b = (b_after - b_before) / b_before
strain_c = (c_after - c_before) / c_before
strain_rms = sqrt((strain_a**2 + strain_b**2 + strain_c**2) / 3)
```

`strain_rms` is nonnegative and does not retain the signs of the individual axis changes. It is **not** a general strain-tensor invariant and **not** an XRD microstrain broadening parameter.

### Labeled `.npz` schema

| Key | Shape | Description |
|---|---|---|
| `two_theta_deg` | `(3500,)` | Common diffraction-angle grid |
| `ideal_xrd` | `(3500,)` | Undeformed, binned stick pattern |
| `perturbed_xrd` | `(3500,)` | Simulated perturbed pattern |
| `lattice_before` | `(3, 3)` | Original conventional lattice |
| `lattice_after` | `(3, 3)` | Deformed conventional lattice |
| `strain_abc` | `(3,)` | Realized a-, b-, and c-axis strains |
| `strain_rms` | `()` | Scalar regression label |
| `delta_angles_deg` | `(3,)` | Changes in alpha, beta, gamma |

Example: load a two-channel model input after running Example 03 with the default arguments.

```python
import numpy as np

path = 'collaboration/outputs/strain_entry_8_seed_0.npz'
with np.load(path, allow_pickle=False) as data:
    x = np.stack([data['ideal_xrd'], data['perturbed_xrd']], axis=0)
    target = float(data['strain_rms'])

x = x[None, :, :]  # (batch=1, channels=2, points=3500)
print(x.shape, target)
```

The ML model must handle scaling and any additional preprocessing explicitly.

## 6. Production dataset v1 (not distributed here)

The separately generated and verified research dataset contains **1,000 unique structures**, with **one ideal reference and 30 perturbed patterns per structure**: 1,000 ideal XRD arrays and 30,000 perturbed XRD arrays. A structure-level split uses 800 training, 100 validation, and 100 test structures (24,000 / 3,000 / 3,000 perturbed XRD samples). All 30 perturbations from a structure remain in the same split.

Production v1 varies lattice stretching/compression only. Lattice shear, thermal displacement, orientation randomness, background, noise, and zero shift are set to zero; grain size is fixed at 10 nm. The target is the realized conventional-axis-length strain RMS. Rejection sampling allocates each structure's 30 samples across zero, very-low, low, low-mid, medium, high, and very-high RMS groups.

Relevant implementation files include:

```text
db_expansion/build_smoke_3x30_v2.py
db_expansion/generate_xrd_dataset_v1.py
db_expansion/fast_xrd_mapping.py
db_expansion/safe_xrd_generation.py
db_expansion/dataset_v1/generation_config.json
```

The production generator requires a source structure database, selected structures with split assignments, a strain sampling plan CSV, and its configuration file. The examples here do **not** constitute a standalone recipe for regenerating all 30,000 samples. Large source databases, model results, and production arrays are excluded from this collaboration package.

## 7. Validation performed

The three demonstration scripts were executed on HANS using AgTlTe2, ASE DB entry 8:

| Check | Observed result |
|---|---|
| Example 01 reference vs earlier ideal grid | Max absolute difference ~1.78e-15 |
| Example 01 ideal peaks | 34 peaks |
| Example 02 same-seed repeated simulations | Exact array equality |
| Example 03 labels vs independently recomputed lattice lengths | Zero observed error |
| Example 03 same-seed repeated simulations | Exact XRD / lattice / label equality |
| Example 02 vs Example 03 perturbed XRD | Max absolute difference ~1.045e-11; equivalent at `atol=1e-8` |

For AgTlTe2 with seed 0, stretch bound 0.01, and shear bound 0:

```text
strain_a   = 0.0009762700785464709
strain_b   = 0.0043037873274482386
strain_c   = 0.002055267521432705
strain_rms = 0.002810682788388219
```

These results demonstrate the specified environment and test case only; they do not establish reproducibility across all structures, operating systems, or dependency versions. The scripts reject existing output filenames, so use a fresh `--name` where supported or a different `--output-dir` for subsequent runs.

## 8. Scope and limitations

- This code generates **synthetic** XRD; it is not yet validated on measured experimental XRD.
- The ideal channel is stick-like, whereas the perturbed channel is a continuous profile.
- Axis-length strain RMS does not characterize the full deformation tensor, symmetry changes, or microstrain broadening.
- The grain-size peak-width model warrants independent angular-unit and physical-consistency validation for quantitative grain-size interpretation.
- The optimized XRD mapping and axial-divergence safety patches temporarily replace process-global functions; do not run them concurrently in multiple threads.
- Do not upload full structure databases, production arrays, passwords, tokens, or lab-internal materials without permission.
